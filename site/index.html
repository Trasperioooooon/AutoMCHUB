MineDeck 我的世界（Minecraft）Windows 一键开服工具

单文件 MineDeck.exe（约 13 MB，零依赖），自动下载 Java 和服务端，图形界面管理服务器；整合包一键导入，内置樱花穿透、OpenFrp 内网穿透，好友异地也能联机。

可选功能：
  • AI 开服助手
  • 游戏内 AI
  • AI 伙伴
  • 音乐共享
下载 GitHub

在发布页下载 MineDeck.exe，放进一个单独的文件夹，双击运行。

三步开服

选好版本点创建，剩下的交给 MineDeck

  1. 1

    下载

    在发布页下载 MineDeck.exe，放进一个独立文件夹。所有数据都存在 exe 旁边：servers/ 实例、runtimes/ Java、cache/ 下载缓存。

  2. 2

    新建服务器

    双击运行，点「新建服务器」→ 选核心 → 选版本 → 选构建 → 勾选 EULA → 创建。

  3. 3

    启动，叫上朋友

    点「▶ 启动」，控制台出现 Done (...)! 即开服成功。局域网玩家连 你的内网IP:端口；异地好友：在「内网穿透」页加一条隧道，把公网地址发给他们。

点创建以后自动完成：匹配并下载便携式 Java → 下载服务端核心 → 运行安装器 → 同意 EULA → 生成配置与启动脚本。全程使用国内镜像加速（BMCLAPI / 清华 TUNA），官方源自动兜底。

功能

开服、排错、联机，再加上可选的 AI

AI 都是可选的：用你自己的 API Key，在「设置 → AI（可选）」里配置好才会启用；不配置就不会连任何 AI 服务，也不影响原来的用法。

AI 开服助手

先查日志和配置再回答，改东西先问你

在标题栏右上角打开「AI 助手」。问它「服务器为什么起不来」，它会先看日志、配置和崩溃报告再回答。

要改配置、换 Java、重启服务器时，先弹确认卡片，你点了才执行；发给 AI 的内容先脱敏，随时可看原文。

报错横幅

服务器起不来？横幅直接说原因

不需要 AI：控制台顶部的报错横幅用本地规则认出 13 类常见错误，比如少装前置模组、客户端模组放进了服务端、端口被占、Java 版本不对，并附上修复办法。

配置了 AI 时，可以点「让 AI 分析」。

游戏内 AI

在聊天里 @AI 提问

玩家在聊天里说「@AI 问题」，回复默认全服可见；/私 只回给自己，/问 只回答、不执行命令，/额度 看还剩几次，/帮助 看用法。

你在面板里勾选的玩家，可以让 AI 执行白名单里的命令：按模板逐个参数校验，op、execute 等写死禁止，搭配一键开启白名单。

AI 伙伴

会跟随、砍树、打怪的伙伴

在 NeoForge 1.21.1 / Forge 1.20.1 服里放 AI 伙伴（基于 PlayerEngine）：聊天里说「@伙伴名 跟着我」「砍 10 个橡木原木」「打附近的僵尸」，它就去做。

禁挖区域、不许打的生物可配；好友的客户端只装一个伙伴模组。

音乐共享

把房主的音乐放给全服听

把房主电脑上音乐软件的声音经 Simple Voice Chat 广播给服里的人，每人可在语音设置里单独调小或静音。

Windows 11 按程序录音，不录游戏声和语音；桥接模组内置，一键安装。

接入 AI（可选）

七个预设，填 Key 就能用

支持 OpenAI 兼容和 Claude 两种协议，内置 DeepSeek、通义千问、Kimi、智谱、OpenAI、Claude、Ollama（本机）七个预设，也可以填自定义地址。

按 LiteLLM 公开价格估算费用，每个功能可设每日额度；Key 经 Windows DPAPI 加密保存；不配置不联网。

功能一览

更多功能

完整的功能表见 README。

  • 十二种服务端核心

    原版 · Paper / Purpur / Leaves / Folia（插件服）· Fabric / NeoForge / Forge（模组服）· Mohist / Banner（模组 + 插件混合服）· Velocity / Waterfall（群组代理端）。

  • Java 全自动

    读取 Mojang 官方元数据精确匹配 Java（8 / 16 / 17 / 21 / 25…），便携部署在 runtimes/，不碰系统环境变量；本机已装的 Java 能复用就不下载。

  • 下载三级加速

    BMCLAPI / 清华 TUNA 优先 → Adoptium / 官方源 → Mojang 官方运行时，逐源故障转移 + 3 轮重试 + SHA 校验。

  • 整合包一键导入

    Modrinth（.mrpack）拖入即开服，自动识别核心、版本、加载器，跳过纯客户端文件；CurseForge zip 配 API Key 可用。

  • 内网穿透

    接入 OpenFrp、樱花frp 和自定义 frps：frpc 自动下载托管、跟随服务器启动，公网地址一键复制。

  • 运维三件套

    世界备份 / 还原（运行中热备）· 崩溃自动重启（退避策略）· 每日定时重启 / 命令 / 备份。

  • 玩家管理

    在线列表（踢出 / OP），白名单、管理员、封禁可视化；停机时直接改名单文件，离线 UUID 自动计算。

  • 资源浏览器

    在实例里直接搜索安装 Modrinth 模组和插件，按核心与版本自动过滤兼容项。

  • 配置全量目录

    约 60 项 server.properties 分 7 组，带搜索、中文说明、范围校验和「需重启」标注，按 MC 版本自动显隐。

  • 控制台增强

    GBK / UTF-8 编码切换（老包乱码克星）、WARN / ERROR 着色、日志过滤、命令历史，常用命令和在线玩家名 Tab 补全。

  • 远程管理

    局域网访问开关 + 密码登录，手机躺床上管服；开放 REST API + Webhook 事件推送。

  • 安全防呆

    老版本自动启用 log4shell 官方缓解方案；清除 JAVA_HOME 等环境污染；下载文件哈希校验；本地 API 带随机令牌。

问答

常见问题

还有别的问题，可以在 GitHub 上提 Issue。

要自己装 Java 吗？

不用。MineDeck 按 Mojang 的版本元数据挑对应的 Java（8 / 17 / 21 / 25……），下载便携版放进 runtimes/，不改系统环境变量；本机已经装好的 Java 能用就直接用。

朋友不在同一个网络，怎么连进来？

在「内网穿透」页添加樱花穿透、OpenFrp 或自定义 frps 的隧道，绑定服务器并打开「跟随实例启动」，开服后把公网地址发给朋友。同一个局域网的朋友直接连 你的内网IP:端口。

支持哪些版本和核心？

MC 1.12.2 到最新版（含 26.x 起的年份版本号），12 种核心：原版、Paper、Purpur、Leaves、Folia、Fabric、NeoForge、Forge、Mohist、Banner、Velocity、Waterfall。Modrinth（.mrpack）和 CurseForge（zip）的整合包可以直接导入。

服务器起不来、报错看不懂怎么办？

看控制台顶部的报错横幅，它会说明原因，比如少装前置模组、客户端模组放进了服务端、端口被占、Java 版本不对，这一步不需要 AI。接入 AI 以后，可以点「让 AI 分析」，或者在「AI 助手」里直接问。

AI 功能要花钱吗？会不会偷偷联网？

AI 是可选的，用你自己的 API Key，费用按服务商的价格付给服务商。MineDeck 会估算每次的花费，每个功能都能设每日额度。不配置 AI 就不会连任何 AI 服务；Key 用 Windows 的 DPAPI 加密保存。

AI 会不会乱改我的服务器？

不会自己动手。读日志、看配置这类操作直接做；改配置、换 Java、重启这类操作只生成确认卡片，你点了确认才执行，所有操作都记在 logs\ops\。游戏内 AI 默认只回答问题，只有你勾选的玩家才能让它执行命令，而且只限白名单里的命令，op、execute 这类一律不执行。

AI 伙伴和音乐共享，好友要装什么？

  • AI 伙伴：好友的客户端只装伙伴模组，发布页有下载。
  • 音乐共享：服务器和好友都装同一版本的 Simple Voice Chat，桥接模组由 MineDeck 装进服务器。

数据存在哪？怎么卸载？

数据都在 exe 所在的文件夹里，只有界面偏好存在 %LocalAppData%\MineDeck。卸载就是删掉这两个文件夹。

Windows 提示「已保护你的电脑」？

exe 没有数字签名，点「更多信息 → 仍要运行」即可。源码公开（MIT），也可以自己构建，步骤见 README 的「从源码构建」。

系统
Windows 10 / 11，推荐 Windows 11：音乐共享在 Windows 11 上可以只录某一个程序；Windows 10 只能录整机的声音。
安装

Java
不用自己装：按版本自动下载便携版，本机已经装好的能用就直接用。
网络
下载 Java 和服务端时要联网：国内镜像加速（BMCLAPI / 清华 TUNA），官方源自动兜底。
窗口
WebView2 原生窗口，缺失时自动用浏览器打开。
AI
