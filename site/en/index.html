MineDeck One-click Minecraft server launcher for Windows

A single MineDeck.exe (about 13 MB, no dependencies) that downloads the right Java and server software, imports Modrinth and CurseForge modpacks, and manages your Minecraft (Java Edition) servers through a GUI, with built-in frp tunnels so friends can join from anywhere.

The app's interface is Chinese only for now. Below, Chinese labels from the app are given with a translation.

Optional:
  • AI server assistant
  • In-game AI
  • AI companions
  • Music sharing

Three steps

Pick a version and click create; MineDeck does the rest

  1. 1

    Download

    Get MineDeck.exe from the releases page and put it in its own folder. All data stays next to the exe: servers/ for instances, runtimes/ for Java, cache/ for downloads.

  2. 2

    Create a server

    Double-click it, then 新建服务器 (New server) → pick a server type → a version → a build → accept the EULA → create.

  3. 3

    Start it and invite friends

    Click ▶ 启动 (Start); when the console shows Done (...)!, the server is up. Friends on your LAN connect to your-LAN-IP:port; for friends elsewhere, add a tunnel on the 内网穿透 (tunnels) page and send them the public address.

After you click create, it does the rest: download a matching portable Java → download the server software → run the installer → accept the EULA → generate the configs and start scripts. Downloads go through mirrors in China (BMCLAPI / Tsinghua TUNA) first, with official sources as automatic fallback.

Features

Hosting, troubleshooting and playing with friends, plus optional AI

All AI features are optional and use your own API key; they turn on only after you set them up in 设置 → AI（可选） (Settings → AI). Without that, MineDeck doesn't connect to any AI service, and nothing else changes.

AI server assistant

Checks the logs and configs first, and asks before changing anything

Open the assistant (AI 助手) from the top-right of the title bar. Ask why your server won't start, and it reads the logs, configs and crash reports before it answers.

Changing a config, switching Java or restarting the server shows a confirmation card first and runs only after you click it. What is sent to the AI is redacted first, and you can always see exactly what was sent.

Error banner

Server won't start? The banner tells you why

No AI needed: the banner at the top of the console uses local rules to recognize 13 kinds of common errors, such as a missing required mod, a client-only mod in the server, a port already in use or the wrong Java version, and shows how to fix them.

With AI set up, you can also click 让 AI 分析 (Ask AI to analyze).

In-game AI

Players ask @AI in chat

Players type @AI and a question in chat; replies are visible to everyone by default. /私 replies only to the asker, /问 answers without running commands, /额度 shows how many questions are left, and /帮助 shows the usage.

Players you tick in the panel can have the AI run allowlisted commands: every argument is checked against a template, and commands such as op and execute are hard-blocked. Turning on the server whitelist takes one click.

AI companions

Companions that follow players, gather wood and fight mobs

Put AI companions (built on PlayerEngine) in NeoForge 1.21.1 and Forge 1.20.1 servers and tell them what to do in chat, for example 「@伙伴名 跟着我」 (follow me), 「砍 10 个橡木原木」 (chop 10 oak logs) or 「打附近的僵尸」 (fight the zombies nearby).

No-dig zones and mobs they must not attack are configurable; friends add just one companion mod to their client.

Music sharing

Play the host's music to everyone on the server

Stream the sound of a music player on the host's PC to everyone on the server through Simple Voice Chat; each player can turn it down or mute it in their voice settings.

On Windows 11 it records just that program, without game sound or voice chat. The bridge mod is built in and installs in one click.

AI setup (optional)

Seven presets: fill in a key and go

OpenAI-compatible and Claude protocols, with presets for DeepSeek, Qwen, Kimi, Zhipu, OpenAI, Claude and Ollama (local), plus a custom address.

Costs are estimated from LiteLLM's public prices, each feature can have a daily limit, and the key is encrypted with Windows DPAPI. Nothing connects until you configure it.

You can also turn on the MCP server, so AI tools such as Claude Desktop, Cherry Studio or Cursor can use MineDeck directly: they read state and logs freely, and any change still waits for your confirmation in MineDeck.

At a glance

More features

The full feature table is in the README (Chinese).

  • 12 server types

    Vanilla · Paper / Purpur / Leaves / Folia (plugins) · Fabric / NeoForge / Forge (mods) · Mohist / Banner (mods + plugins) · Velocity / Waterfall (proxies).

  • Automatic Java

    Matches Java exactly from Mojang's metadata (8 / 16 / 17 / 21 / 25 …) and installs it portably in runtimes/ without touching system environment variables; reuses a Java you already have when it fits.

  • Three-tier downloads

    BMCLAPI / Tsinghua TUNA first → Adoptium / official sources → Mojang's runtimes, with per-source failover, 3 retries and SHA checks.

  • Modpack import

    Drop in a Modrinth .mrpack and get a server (server type, version and loader detected, client-only files skipped); CurseForge zips work with an API key.

  • Built-in tunnels

    OpenFrp, SakuraFrp and self-hosted frps: frpc is downloaded and managed for you, starts with the server, and the public address copies in one click.

  • Backups, restarts, schedules

    World backup / restore (hot backups while running) · crash auto-restart (with backoff) · daily scheduled restarts, commands and backups.

  • Player management

    Online list (kick / OP); whitelist, ops and bans in the GUI, edited straight in the files while the server is stopped, with offline UUIDs computed for you.

  • Resource browser

    Search and install Modrinth mods and plugins from inside an instance, filtered for your server type and version.

  • All of server.properties

    About 60 server.properties settings in 7 groups, with search, descriptions, range checks and "needs restart" tags, shown or hidden by MC version.

  • Better console

    GBK / UTF-8 switch (fixes garbled text in old packs), WARN / ERROR colors, log filter, command history, and Tab completion for common commands and online player names.

  • Remote management

    LAN access with a password, so you can manage servers from your phone; an open REST API and webhook events.

  • Safety guards

    Log4Shell mitigation turned on for old versions; JAVA_HOME and similar environment pollution cleared; download hash checks; a random token on the local API.

FAQ

Frequently asked questions

Anything else? Open an issue on GitHub.

Do I need to install Java myself?

No. MineDeck reads Mojang's version metadata to pick the matching Java (8 / 17 / 21 / 25 …), downloads a portable build into runtimes/ and leaves your system environment variables alone; if a Java already installed on your PC works, it uses that.

My friends aren't on the same network. How do they join?

On the 内网穿透 (tunnels) page, add a SakuraFrp, OpenFrp or self-hosted frps tunnel, bind it to your server and turn on 跟随实例启动 (start with the server); once the server is up, send your friends the public address. Friends on the same LAN connect directly to your-LAN-IP:port.

Which versions and server types are supported?

MC 1.12.2 up to the latest release (including the year-based version numbers from 26.x on), with 12 server types: Vanilla, Paper, Purpur, Leaves, Folia, Fabric, NeoForge, Forge, Mohist, Banner, Velocity and Waterfall. Modrinth (.mrpack) and CurseForge (zip) modpacks can be imported directly.

My server won't start and I can't read the error. What now?

Look at the error banner at the top of the console: it explains the cause, such as a missing required mod, a client-only mod in the server, a port already in use or the wrong Java version. This step doesn't need AI. With AI set up, you can click 让 AI 分析 (Ask AI to analyze) or just ask in the AI assistant.

Do the AI features cost money? Will MineDeck go online behind my back?

AI is optional and uses your own API key; you pay the provider at the provider's prices. MineDeck estimates what each request costs, and every feature can have a daily limit. If you don't set up AI, MineDeck doesn't connect to any AI service; the key is stored encrypted with Windows DPAPI.

Will the AI mess with my server?

It doesn't act on its own. Reading logs and checking configs happen directly; changing configs, switching Java or restarting only produce a confirmation card and run after you confirm, and every operation is logged in logs\ops\. The in-game AI only answers questions by default; only players you tick can have it run commands, and only allowlisted ones. Commands like op and execute are never run.

What do friends need to install for AI companions and music sharing?

  • AI companions: friends install only the companion mod in their client; it's on the releases page.
  • Music sharing: the server and your friends install the same version of Simple Voice Chat; MineDeck installs the bridge mod into the server.

Where is my data, and how do I uninstall?

Everything is in the folder that holds the exe; only interface preferences are stored in %LocalAppData%\MineDeck. To uninstall, delete those two folders.

Windows says "Windows protected your PC"?

The exe isn't digitally signed. Click "More info → Run anyway". The source is public (MIT), and you can build it yourself; see building from source in the README.
