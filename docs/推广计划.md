# 推广计划：让人和 AI 找得到 MineDeck

写于 2026-10-31，给维护者看。目标有两个：

- 想开服的玩家搜「我的世界怎么开服」「MC 开服器」时能看到 MineDeck；
- 别人问 AI「有什么好用的 MC 开服工具」时，AI 能找到并推荐它。

## 1. 思路

AI 和人找东西的路子差不多。现在的 AI 助手回答这类问题时，大多会先联网搜索，再引用搜到的网页；没联网的，靠的是训练时见过的网页。所以两件事最要紧：

1. **网上要有足够多、说得清楚的页面提到它**。每次都用同一个名字和同一句定位：「MineDeck，Windows 上的我的世界一键开服工具」。名字要和定位一起出现，因为单搜「MineDeck」会混进 Steam Deck 的整合包。
2. **这些页面要在 AI 会去搜的地方**：
   - 国外的 AI（ChatGPT、Claude、Perplexity、Gemini）主要搜 Bing、Google 这类搜索引擎，GitHub 仓库页本身就会被收录；
   - 国内的 AI（豆包、元宝、Kimi、DeepSeek、通义）更多引用国内平台的内容，比如知乎、B 站、CSDN、掘金、微信公众号。GitHub 在国内的收录一直不好，所以国内要靠这些平台上的文章和视频。

人也是这样：国内的 MC 玩家主要在 B 站、贴吧、MC 百科、QQ 群里找工具，开发者看 V2EX、HelloGitHub、小众软件。

## 2. 现在的状况（2026-10-31 查的）

- 仓库是公开的，MIT 许可，1 颗星，有 16 个 topics。仓库描述还停在 v2.6.1，没提 AI 这些新功能；没有设主页链接，没开 Discussions。
- README 没有一张截图，全文没出现「我的世界」。国内玩家最常搜的正是「我的世界开服」。
- 用搜索引擎搜「MineDeck Minecraft」找不到这个项目，只有几个叫 Mine Deck、DeckCraft 的 Steam Deck 整合包。好处是没有同名的开服工具，名字可以放心用。

## 3. 时间安排

- **现在（测试期间）**：打地基。改好 README 和仓库信息，补上截图，备好各平台的文案。收录要几周才见效，越早越好。
- **正式版 v2.9.0 发布时**：集中投稿、发视频、发帖。测试版的小问题多，第一印象很重要，大范围推广等正式版。
- **之后**：每个版本的发布说明写清楚；有人在评论或 Issue 里提问就认真答，这些问答本身也会被收录。

## 4. 仓库本身

### 4.1 README（已改，见仓库首页）

- 标题和第一段带上「我的世界」「一键开服」「内网穿透」「整合包」「AI」这些大家会搜的词。
- 放截图，每张图都写清楚的替代文字（alt）。AI 读网页时看的是文字，替代文字能让它知道图里是什么。
- 加「常见问题」：标题直接写成大家会问的问题，比如「朋友不在同一个网络怎么连进来」。AI 搜索很喜欢引用这种一问一答的段落。
- 末尾加一段英文简介，让英文的搜索和 AI 也看得懂。界面目前只有中文，英文简介里会写明这一点。

### 4.2 要你在 GitHub 上点的（我改不了仓库设置）

在仓库首页右侧 About 旁的齿轮里：

- **Description** 改成：

  ```
  我的世界（Minecraft）Windows 一键开服工具：单文件 exe，自动装 Java 和服务端，整合包导入、内网穿透（樱花 / OpenFrp）；可选 AI 开服助手、游戏内 AI、AI 伙伴和音乐共享。One-click Minecraft server launcher for Windows.
  ```

- **Topics** 再加 4 个（上限 20 个）：`ai-assistant`、`llm`、`frp`、`simple-voice-chat`。
- **Website** 先填发布页 `https://github.com/Trasperioooooon/MineDeck/releases`，以后有介绍页再换。

在 Settings 里：

- **Social preview**：上传 `assets/social-preview.png`（1280×640）。链接分享到 QQ、Discord、X 时会显示这张卡片。
- **Features → Discussions**：打开。问答放在这里，搜索引擎会收录，也比 Issue 更适合「怎么用」这类问题。

### 4.3 Software Heritage 存档（一分钟）

打开 <https://archive.softwareheritage.org/save/>，填仓库地址 `https://github.com/Trasperioooooon/MineDeck` 提交。

Software Heritage 是公开源码的长期存档，不少代码大模型的训练数据（比如 The Stack）取自这里。

- 它本来也会陆续抓取 GitHub 上的公开仓库，提交只是让它马上存一份。
- 存进去以后，以后的模型更可能「见过」MineDeck。

### 4.4 Gitee 镜像（建议）

在 Gitee 新建仓库时选「从 GitHub 导入」，填仓库地址即可。

- 国内用户打不开 GitHub 时有个去处，百度也能收录 Gitee。
- 以后做国内下载加速时，也用得上这个镜像。
- 要自动同步的话，可以用 GitHub Actions（比如 Yikun/hub-mirror-action）。这要在仓库里存一个 Gitee 的令牌，到时我来配，你只要把令牌填进 Secrets。

### 4.5 llms.txt（不急）

llms.txt 是给 AI 看的网站简介，有人提议放在网站根目录。2026 年的统计显示，主流 AI 的爬虫基本不读它，也没有哪家大厂说过会用。我们现在没有网站，以后做介绍页时顺手加上就行，不用专门做。

### 5.1 V2EX「分享创造」

> **做了个我的世界一键开服工具 MineDeck：单文件 exe，自带内网穿透，还能让 AI 帮你排错、在游戏里当伙伴**
>
> 我平时和朋友开 NeoForge、Forge 的整合包服。每次都要折腾 Java 版本、安装器、端口映射，报错也看不懂，所以写了这个工具。现在的样子：
>
> - 单文件 exe，不用装 Java：选好核心和版本点创建，自动下载对的 Java 和服务端，跑完安装器、同意 EULA；
> - 整合包（Modrinth / CurseForge）拖进来就能开服；
> - 内置樱花穿透、OpenFrp，好友异地也能连；
> - 控制台顶部直接告诉你报错是什么原因（少前置、客户端模组进了服务端、端口被占等），不用 AI；
> - 可选接 AI（自己的 Key，DeepSeek、通义、Kimi、Claude 等都行）：
>   - 应用里的助手先看日志再回答，要改配置先给你确认；
>   - 游戏里 `@AI` 提问；
>   - 放一个会跟随、砍树、打怪的 AI 伙伴；
> - 还能把电脑上放的歌经 Simple Voice Chat 放给服里的人听。
>
> Go 写的，界面是 WebView2，MIT 开源。地址：https://github.com/Trasperioooooon/MineDeck
>
> 欢迎试用和提意见，尤其是 AI 那部分想听听大家怎么看。
