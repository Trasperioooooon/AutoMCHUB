# MineDeck 测试版：好友测试指南

谢谢你帮忙测试！MineDeck 是房主用来开服的工具。这次的测试版 v2.9.0-beta.1 加了游戏内 AI、AI 伙伴和音乐共享。你只要照下面做，把遇到的情况告诉房主就行，大约 20 分钟。

先看你属于哪种情况：

- **只是进房主的服玩**（大多数人）：看第一节。
- **想自己用 MineDeck 开个服试试**：看第二节。
- **想让 AI 智能体帮你测**：看第三节。

## 一、进服帮忙测

### 1. 准备客户端

- 需要 Minecraft Java 版和一个启动器，HMCL、PCL2 都行。
- 版本和加载器问房主，比如 NeoForge 1.21.1 或 Forge 1.20.1。
- 整合包服就照整合包装。

### 2. 按房主的说明装模组

房主会发给你一段说明，照着装进 `.minecraft` 的 `mods` 目录。启动器开了版本隔离的，是 `.minecraft\versions\<版本名>\mods`。可能要装这两样：

- **伙伴模组**（服务器开了 AI 伙伴时）：
  - 文件名像 `minedeck-companion-neoforge-1.21.1-0.2.0.jar`。
  - 找房主要，或者在[发布页](https://github.com/Trasperioooooon/MineDeck/releases/tag/v2.9.0-beta.1)下载。NeoForge 1.21.1 的服下 `neoforge-1.21.1` 那个，Forge 1.20.1 的服下 `forge-1.20.1` 那个。
  - 只装这一个就行，PlayerEngine 这些不用装。
- **Simple Voice Chat**（服务器开了音乐共享时）：版本要和服务器的一样，问房主是哪个版本。

GitHub 打不开或下载很慢的话，直接找房主要文件。

### 3. 进服

用房主给的地址进服。用樱花穿透时，地址类似 `xxx.natfrp.cloud:12345`。

进服失败的话，把报错界面截图发给房主。尤其是看到中文提示的情况，比如「要装伙伴模组」。

### 4. 试这些（能试几个试几个）

**游戏内 AI**（在聊天栏里打）：

- `@AI 今晚怎么打末影龙`：全服都能看到回复，开头是 `[AI→你的名字]`，中文正常。
- `@AI /私 你好`：只有你看得到回复。可以问问旁边的人看不看得到。
- `@AI /帮助`、`@AI /额度`：看用法、看今天还能问几次。
- `@AI 把天气改晴`：房主没给你授权时，AI 只回答、不执行。授权了的话，天气会变。
- `@AI 给我 op`：不管有没有授权，都不应该执行。

**AI 伙伴**（服务器有伙伴时，名字问房主，这里用「小方」举例）：

- `@小方 跟着我`、`@小方 砍 10 个橡木原木`、`@小方 跟大家打个招呼`。
- 房主授权了你，伙伴应该去做，做完会私下告诉你。
- 没授权的话，它会说要服主授权，自己不动。

**音乐共享**（房主放歌的时候）：

- 你能听到房主电脑上放的音乐，延迟不明显。
- 按 V → 「调整音量」，找到「MineDeck 音乐共享」拉到 0：音乐静音了，但别人说话照样听得到。
- 房主停止放歌、关服时，音乐马上停。

### 5. 告诉房主结果

不管成没成功都可以说一声，有问题就按第四节的格式写。

## 二、自己开服试试（可选）

1. 在[发布页](https://github.com/Trasperioooooon/MineDeck/releases/tag/v2.9.0-beta.1)下载 `MineDeck.exe`。新建一个空文件夹（比如 `D:\MineDeck-beta`），把它放进去，双击运行。
   - 如果出现「Windows 已保护你的电脑」，点「更多信息 → 仍要运行」。这是因为测试版没有数字签名。
2. 点「新建服务器」，选核心（想装模组就选 NeoForge 或 Forge，只想玩原版就选 Paper），选版本，勾上 EULA，点创建。Java 和服务端会自动下载。
3. 点「启动」，控制台出现 `Done` 就开好了。自己用 `127.0.0.1` 进服；Windows 防火墙弹窗时选「允许访问」。
4. 有 AI 的 API Key（比如 DeepSeek、通义千问）的话，可以再试 AI：
   1. 到「设置 → AI（可选）」，选服务商，填 Key。
   2. 点「获取模型列表」，选一个模型。
   3. 点测试连接，再保存。
   4. 点窗口右上角的「AI 助手」，问「服务器现在怎么样」，或者「把最大人数改成 10」。要改东西时，它会先弹一张确认卡片。
5. 界面上有看不懂、不好用、出错的地方，截图告诉房主。

完整的测试清单在[《测试计划》](测试计划.md)里，有兴趣可以挑着测。

## 三、让 AI 智能体帮你测（可选）

如果你用的 AI 智能体能操作电脑，可以让它帮你测。

1. 把[《测试计划》](测试计划.md)发给它，打不开 GitHub 的话找房主要文件。
2. 对它说：

> 请按这份测试计划测试 MineDeck v2.9.0-beta.1，先读第 3 节「给 AI 测试员的说明」再开始。只测你能做的和我能配合的项，游戏里的操作告诉我怎么做，我来做、告诉你结果。API Key 我自己填，你不要经手。最后按第 5 节的格式写报告，附上第 6 节的汇总表。

3. 测完把它写的报告发给房主。

## 四、反馈怎么写

一个问题写一条，复制下面的格式填：

```
【做了什么】比如：在聊天里说 @AI /私 你好
【结果】成功 / 失败 / 一部分成功
【预期】只有我看得到回复
【实际】旁边的人也看到了
【电脑】Windows 11（Win+R 输入 winver 能看到）
【截图】有的话附上
```

- **截图最有用**，报错界面、聊天栏、奇怪的地方都可以截。
- 游戏崩了的话，把 `.minecraft\crash-reports\` 里最新的文件发给房主。开了版本隔离的在 `.minecraft\versions\<版本名>\` 下面。
- 不要把 API Key、密码发到群里。
