## 新功能：MCP 接口

MCP 是 AI 工具调用外部程序的通用协议。打开以后，这台电脑上的 Claude Desktop、Cherry Studio、Cursor、VS Code 这些 AI 工具就能直接使用 MineDeck。

- **怎么用**：在「设置 → AI（可选）→ MCP 接口」打开开关，点「复制配置…」，选你用的工具，按说明粘贴进去。默认是关着的。
- **AI 工具能做什么**：查服务器状态、看日志和配置这类操作直接执行。改配置、重启服务器这类操作只会提出请求，MineDeck 会弹出提示，在「AI 助手」面板顶上出现确认卡片，你点了确认才执行。只能由人操作的功能，外部 AI 工具看不到。
- **安全**：只接受这台电脑上的连接，要带访问令牌。令牌加密保存，可以随时重置。发给 AI 工具的内容和应用内助手一样先脱敏，看不到 Windows 用户名和局域网 IP。
- **不需要 MineDeck 自己的 AI Key**：用的是那个 AI 工具自己的模型。

## AI 伙伴：伙伴模组 0.2.1

- **不再淹死**：停下来的伙伴站在水里，会像普通生物一样浮上来，以前过半分钟左右会淹死。
- **给东西时说实话**：按实际交出的个数报结果。一个都没给出去时说「失败了」，并写明原因，比如对方不在同一个维度、背包里没有；只给了一部分时说「没做够」。以前一律报「做完了」。
- **重启后马上列出伙伴**：重启服务器以后，「伙伴」标签一连上就列出存档里的伙伴，以前要等两秒左右。

**升级**：
- 服务器上的伙伴模组：在「伙伴」标签里点「安装」，会换成 0.2.1，要先停服。
- 好友的客户端：把伙伴模组换成 0.2.1（见下面的附件），版本要和服务器的一样。版本不一样时，Forge 1.20.1 的多人游戏列表里会显示红色的「不兼容」标记，但实际能进服。

## 其他

## 已知情况

- **没有数字签名**：第一次运行时，Windows 可能提示「Windows 已保护你的电脑」，点「更多信息 → 仍要运行」。
- **国内下载**：AI 伙伴依赖的 PlayerEngine 和 Architectury API 从 Modrinth 下载，AI 的价格数据从 GitHub 下载，国内网络可能慢或下载不了。下载速度的问题放到正式版之前统一处理。
- **Windows 10 上的音乐共享**：只能录整机的声音，会把游戏声音也录进去，开始前会提醒。
- **MCP 接口还没在真 Windows 上和真的 AI 工具一起测过**：
  - 在云端是用官方的客户端库，对 wine 里跑的 MineDeck 测的。
  - Cursor 的配置写法还没核实。
  - Claude Desktop 启动 `MineDeck.exe -mcp` 时会不会有短暂的转圈光标，要在真机上看。
- **AI 伙伴**：MineDeck 和伙伴模组在云端的无头服务器上联调全部通过，但还没和玩家的正式客户端、真实的 AI Key 一起测过。
- **游戏内 AI 和音乐共享**：云端只用假的服务器测过。
