## 这一版有什么

和 v2.6.1 相比，新加了下面这些功能。都是可选的：不配置就不会联网，也不影响原来的用法。

- **AI 接入**：在「设置 → AI（可选）」里填自己的 API Key 就能用。
  - 支持 OpenAI 兼容和 Claude 两种协议。
  - 内置七个预设：DeepSeek、通义千问、Kimi、智谱、OpenAI、Claude、Ollama（本机），也可以填自定义地址。
  - 按 LiteLLM 的公开价格估算费用，每个功能可以设每日额度。
  - Key 用 Windows 的 DPAPI 加密保存。
- **应用内 AI 助手**：在标题栏右上角的「AI 助手」打开。
  - 问它「服务器为什么起不来」，它会先看日志、配置和崩溃报告再回答。
  - 要改配置、换 Java、重启服务器时，先弹确认卡片，你点了才执行。
- **报错横幅**：不需要 AI。控制台顶部直接说明出了什么问题，比如少装前置模组、客户端模组放进了服务端、端口被占、Java 版本不对等 13 类。配置了 AI 时，可以点「让 AI 分析」。
- **游戏内 AI**：在服务器详情的「游戏内 AI」标签里打开。
  - 玩家在聊天里说「@AI 问题」，回复全服都看得到。
  - `/私` 只回给自己，`/问` 只回答、不执行命令，`/额度` 看还剩几次，`/帮助` 看用法。
  - 你在面板里勾选的玩家，可以让 AI 执行白名单里的命令，比如改天气、改时间。
- **音乐共享**：在「音乐共享」标签里打开。
  - 把你电脑上音乐软件的声音，经 Simple Voice Chat 广播给服里的人。
  - 每个人都能在语音设置里单独调小或静音。
  - Windows 11 上可以只录某一个程序，不会把游戏声音和语音录进去。
- **AI 伙伴**：在「伙伴」标签里打开，支持 NeoForge 1.21.1 和 Forge 1.20.1。
  - 在服务器里放 AI 伙伴，基于 PlayerEngine。
  - 在聊天里说「@伙伴名 跟着我」「@伙伴名 砍 10 个橡木原木」，它就去做。
  - 好友的客户端只要装一个伙伴模组。

其他变化：

- **界面 v5**：新图标、新的默认配色「方块」、内嵌字体（Geist、Noto Sans SC）、连续曲率圆角，冷启动时有启动画面。
- **加密保存**：CurseForge Key 和内网穿透的凭据改成加密保存，旧配置第一次启动时自动迁移。
- **修复**：聊天里打一句「X joined the game」就能伪造进服。
- **操作记录**：界面上的改动、AI 的提案和执行，都记进程序目录的 `logs\ops\`。

## 下载哪个文件

| 文件 | 给谁 |
|---|---|
| `MineDeck.exe` | 开服的人（房主）。放进一个单独的文件夹，双击运行。 |
| `minedeck-companion-neoforge-1.21.1-0.2.0.jar` | 用了 AI 伙伴的 NeoForge 1.21.1 服上的好友：放进客户端的 `mods` 目录 |
| `minedeck-companion-forge-1.20.1-0.2.0.jar` | 同上，Forge 1.20.1 的服 |
| `SHA256SUMS` | 校验和，自动更新会用到，一般不用管 |

房主不用单独下载伙伴模组，在「伙伴」标签里点「安装」就会装进服务器。

## 从 v2.6.1（AutoMCHUB）升级

- **要手动下载一次**：改名以后，老版本的自动更新找不到新文件，会提示「无法获取该版本的官方校验和」。
  - 请手动下载 `MineDeck.exe`，放进原来 `AutoMCHUB.exe` 所在的文件夹运行。服务器、Java 和设置都会接着用。
  - 确认没问题后，可以删掉 `AutoMCHUB.exe`。
- **开机自启会关掉**：旧的自启项用的是 AutoMCHUB 的名字，新版会删掉它。需要的话，到「设置 → 启动与托盘」重新打开。

## 已知情况

- **没有数字签名**：第一次运行时，Windows 可能提示「Windows 已保护你的电脑」，点「更多信息 → 仍要运行」。
- **国内下载**：AI 伙伴依赖的 PlayerEngine 和 Architectury API 从 Modrinth 下载，AI 的价格数据从 GitHub 下载，国内网络可能慢或下载不了。下载速度的问题放到正式版之前统一处理。
- **Windows 10 上的音乐共享**：只能录整机的声音，会把游戏声音也录进去，开始前会提醒。
- **云端测不了的部分**：游戏内 AI 和音乐共享在云端只用假的服务器测过。AI 伙伴模组在云端的无头服务器上测过，但还没和玩家的正式客户端、真实的 AI Key 一起测过。这些正是这次要确认的。
